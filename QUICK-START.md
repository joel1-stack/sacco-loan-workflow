# QUICK START - Execute Now

## Step 1: Open Jira (2 min)
- Go to: https://your-site.atlassian.net
- Click: **Create Project**
- Name: **Community Health Outreach 2026**
- Type: **Kanban** or **Scrum**

---

## Step 2: Create Workflow Statuses (3 min)

Go to: **Project Settings → Statuses**

Create these statuses:
```
BACKLOG
PLANNING
IN PROGRESS
REVIEW
APPROVED
COMPLETED
BLOCKED
CANCELLED
```

---

## Step 3: Create Sample Tasks (5 min)

Create these tasks:

| Task | Assignee | Status |
|------|----------|--------|
| Plan community survey | John | PLANNING |
| Train field team | Mary | IN PROGRESS |
| Collect health data | Peter | BACKLOG |
| Review evidence | Mary | BACKLOG |
| Submit donor report | John | BACKLOG |

---

## Step 4: Move Tasks Through Workflow (3 min)

Practice moving tasks:
1. Click task → Change status
2. Add comment when changing
3. Upload a file as evidence

---

## Step 5: Create Report (2 min)

Create a new task called "Weekly Report" with:
- Description: Summary of progress
- Checklist: Tasks completed, issues, next steps

---

## Done!

You now have:
- Project created
- Workflow set up
- Tasks created
- Team assigned
- Progress tracked
- Evidence uploaded
- Report created
