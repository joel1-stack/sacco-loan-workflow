# People Level

## Roles and Responsibilities Matrix

---

## Team Roles

### Program Manager (PM)
**Responsibilities:**
- Overall project ownership
- Planning and prioritization
- Resource allocation
- Status reporting
- Final approvals

**Can Do:**
- Create/edit all tasks
- Move tasks to any status
- Assign team members
- View all reports

---

### Field Officer
**Responsibilities:**
- Execute field activities
- Collect data and evidence
- Document progress
- Report issues

**Can Do:**
- Move tasks: IN PROGRESS → REVIEW
- Upload evidence
- Add comments
- View assigned tasks

---

### M&E Officer (Monitoring & Evaluation)
**Responsibilities:**
- Review evidence quality
- Verify data accuracy
- Approve or request changes
- Ensure standards met

**Can Do:**
- Move tasks: REVIEW → APPROVED
- Request revisions
- Add review comments
- View all evidence

---

### Finance Officer
**Responsibilities:**
- Track budget
- Process payments
- Verify expenses
- Financial reporting

**Can Do:**
- Approve budget items
- View financial tasks
- Add budget notes
- Flag overspending

---

### Partner Organization
**Responsibilities:**
- Provide support
- Share resources
- Coordinate activities

**Can Do:**
- View project status
- Add comments
- Upload shared documents
- Limited editing

---

## RACI Matrix

| Activity | PM | Field | M&E | Finance | Partner |
|----------|-----|-------|-----|---------|---------|
| Planning | **A** | C | C | C | I |
| Field Work | I | **A** | C | I | S |
| Data Collection | I | **A** | R | I | I |
| Review | C | C | **A** | I | I |
| Reporting | **A** | C | R | R | I |
| Budget Approval | **A** | I | I | R | I |

**R** = Responsible, **A** = Accountable, **C** = Consulted, **I** = Informed, **S** = Support
