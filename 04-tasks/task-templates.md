# Tasks Level

## Task Templates by Workflow Stage

---

### BACKLOG Tasks
- [ ] Identify project need
- [ ] Create project brief
- [ ] Estimate resources
- [ ] Add to backlog

### PLANNING Tasks
- [ ] Define objectives
- [ ] Identify team members
- [ ] Create timeline
- [ ] Set budget
- [ ] Identify partners
- [ ] Plan activities
- [ ] Prepare materials
- [ ] Get approval

### IN PROGRESS Tasks
- [ ] Conduct field visit
- [ ] Implement activity
- [ ] Collect data
- [ ] Take photos/evidence
- [ ] Record observations
- [ ] Update progress
- [ ] Handle issues

### REVIEW Tasks
- [ ] Check evidence completeness
- [ ] Verify data accuracy
- [ ] Review report draft
- [ ] Check budget alignment
- [ ] Approve or request changes

### APPROVED Tasks
- [ ] Finalize report
- [ ] Submit to donor
- [ ] Share with management
- [ ] Archive documents
- [ ] Update records

### COMPLETED Tasks
- [ ] Close project
- [ ] Document lessons learned
- [ ] Release resources
- [ ] Update database

---

## Task Card Template

```
TASK: [Task Name]
ASSIGNEE: [Person]
STATUS: [Current Status]
DUE DATE: [Date]
PRIORITY: [High/Medium/Low]

DESCRIPTION:
[What needs to be done]

ACCEPTANCE CRITERIA:
- [ ] Criteria 1
- [ ] Criteria 2
- [ ] Criteria 3

EVIDENCE REQUIRED:
- [ ] Document type 1
- [ ] Document type 2

BLOCKERS:
[Any current blockers]

NOTES:
[Additional information]
```

---

## Task Example

```
TASK: Conduct Community Health Survey
ASSIGNEE: Mary (Field Officer)
STATUS: IN PROGRESS
DUE DATE: 2026-09-25
PRIORITY: High

DESCRIPTION:
Visit 50 households in target community to collect health data using standardized questionnaire.

ACCEPTANCE CRITERIA:
- [ ] 50 households surveyed
- [ ] All forms complete
- [ ] Photos taken
- [ ] Data entered in system

EVIDENCE REQUIRED:
- [ ] Completed questionnaires
- [ ] Attendance sheet
- [ ] Activity photos
- [ ] GPS coordinates

BLOCKERS:
None currently

NOTES:
Weather forecast looks good. Partner organization confirmed support.
```

*Tasks are the smallest units of work that people can complete and track.*
