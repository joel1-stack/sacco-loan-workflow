## What This Project Demonstrates

### The Core Skill
You are not just learning "how to use Jira."

You are learning:
> **How does a real organization turn a business process into a collaborative digital operating workflow?**

### The Hierarchy
1. **Business** - What does the organization do?
2. **Process** - How does the work flow?
3. **Workflow** - What are the stages in Jira?
4. **Tasks** - What specific work needs to be done?
5. **People** - Who does what?
6. **Progress** - Where is the work now?
7. **Evidence** - What proof exists?
8. **Reports** - What do we tell stakeholders?
9. **Collaboration** - How do we work together?
10. **Automation** - How can the system help?

### The Example
**NGO Community Health Project**

- Planning
- Field Activities
- Data Collection
- Review
- Reporting
- Closure

## Workshop Exercise

### Team Structure
- **Team Size:** 3 people
- **Time:** 15 minutes
- **Tools:** Jira + Confluence

### Your Task
1. Create a Jira project with workflow statuses
2. Create a Confluence space for documentation
3. Create sample tasks in Jira
4. Create project plan page in Confluence
5. Assign team members
6. Track progress in Jira
7. Upload evidence to Confluence
8. Link Jira tasks to Confluence pages
9. Generate a report
