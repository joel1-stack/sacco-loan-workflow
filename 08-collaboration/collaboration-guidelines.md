|---------|---------|---------------|

| Use Case | Jira | Confluence |
|----------|------|------------|

| "What is the status?" | ✅ Dashboard | |
| "Where is the project plan?" | | ✅ Page |
| "What is our policy?" | | ✅ Knowledge base |

## Confluence Features for NGOs

### Guest Access (External Partners)
- Share project timelines with donors
- Give partners view-only access to reports
- Keep sensitive data internal

### Permissions (Access Control)
- **Admin:** Program Manager
- **Editor:** Team members
- **Commenter:** Partners
- **Viewer:** Donors, stakeholders

### Company Hub (Single Source of Truth)
- All project documentation in one place
- Easy search and discovery
- Always up to date

### Automation (Repetitive Work)
- Auto-create meeting notes
- Auto-update status pages
- Auto-send reminders

### Insights (Activity Tracking)
- See who viewed what
- Track page engagement
- Measure team activity

---

## Collaboration Rules

### 1. Status Updates
- Update Jira task status daily
- Add comment when changing status
- Tag relevant team members
- Mention blockers immediately

### 2. Documentation
- Create Confluence page for major decisions
- Link Jira tasks to Confluence pages
- Keep knowledge base updated
- Version control documents

### 3. Evidence Sharing
- Upload to Confluence page (organized)
- Link from Jira task (traceability)
- Use standard naming convention
- Add description to all uploads

### 4. Handoffs
- Brief successor before handoff
- Document in Confluence
- Update Jira status
- Confirm receipt
