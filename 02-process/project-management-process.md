# Process Level

## Business Process: Project Management

### Process Overview

This document defines the end-to-end process for managing community projects within the organization.

---

## Process Map

```
PLANNING → COORDINATION → EXECUTION → DATA COLLECTION → REVIEW → REPORTING → CLOSURE
```

---

## Process Stages

### 1. Planning
- Define project objectives
- Identify resources needed
- Create timeline
- Assign team roles
- Set budget

### 2. Coordination
- Engage partners
- Schedule activities
- Confirm logistics
- Communicate with stakeholders

### 3. Execution
- Conduct field activities
- Implement project tasks
- Document progress
- Handle issues

### 4. Data Collection
- Gather evidence
- Collect attendance
- Record observations
- Take photos/documents

### 5. Review
- Verify completeness
- Check quality
- Approve or request changes
- Sign off

### 6. Reporting
- Compile reports
- Submit to donors
- Share with management
- Archive documents

### 7. Closure
- Finalize all tasks
- Close project
- Document lessons learned
- Update records

---

## Process Outputs

| Stage | Output |
|-------|--------|
| Planning | Project Plan |
| Coordination | Confirmed Schedule |
| Execution | Activity Records |
| Data Collection | Evidence Package |
| Review | Approved Report |
| Reporting | Submitted Reports |
| Closure | Project Closure Document |

---

*This process flows from one stage to the next, with clear inputs and outputs at each step.*
